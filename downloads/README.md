O APK anterior foi sinalizado pelo Microsoft Defender como `Trojan:Script/Ulthar.A!ml`. O APK original e a versão revisada não tiveram detecções na análise local com ClamAV 1.5.4, base diária 28171 de 01/11/2026. Isso **não confirma falso positivo nem aprovação pelo Defender**. Se o bloqueio continuar, mantenha a proteção e solicite revisão à Microsoft.

A versão revisada está sem depuração e componentes de teste no APK distribuído, traz regras explícitas de backup e corrige um caso de ordenação do histórico. A assinatura de desenvolvimento anterior foi preservada para atualização sem desinstalação. Não é uma versão assinada para publicação na Play Store.

O programa funciona em Android 8 ou posterior; APK não é instalador para Windows. Relatórios em [review/](review/). Não há teste físico em celular nesta entrega.
